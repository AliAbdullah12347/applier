▶ applier

This extension talks to applier running on this computer and to nothing else.

1. Start the server

python -m applier gui

It prints a link. Everything after the #t= is the session token.

2. Paste the token

A note on the token

The token is minted fresh every time applier gui starts, so after a restart you will need to paste the new one. That is deliberate: it means a token that leaks stops working as soon as you restart the server.

It is stored in this extension's local storage, which no website and no other extension can read. It is never sent anywhere except to 127.0.0.1 on your own machine.
